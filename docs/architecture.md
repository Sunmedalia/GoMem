# 引擎与证据契约

`pkg/memory` → `pkg/symbols` / `pkg/object` → `pkg/plugin` → `pkg/evidence` → `internal/store` → CLI / TUI。

公开扩展接口分别为 `MemorySource`、`MemoryLayer`、`Translator`、`SymbolTable`、`ObjectReader`、`Plugin`、`EvidenceStore`。插件通过编译注册；注册在任务开始前完成。取证核心不依赖 Python 或 Volatility。

## 读取与地址

文件只读，单次读取最多 16MiB。映射段排序、检查溢出、拒绝重叠和截断；段之间的洞保留为不可读。ELF 的 `Memsz-Filesz` 区域不会补零冒充证据。虚拟读取在页边界或大页边界拆分，缺页错误带地址、长度、层名和原因。

Intel 转换器支持 x86、PAE 和四级 x64，拒绝非 canonical 地址，保留有效写权限和 NX 属性，缓存最多 1024 个页表页。进程空间使用独立转换器；缓存不会跨根页表混用。五级 x64、其他 ISA 和交换页解析仍在验收缺口中。

给定精确符号时，可在部分 Linux x64 内核上从物理 banner 与初始页表的符号差值生成 DTB 候选。根自身映射、banner 物理副本和完整内容都必须经页表转换验证；歧义或损坏会失败。虚拟 slide 仍需提供，适用范围见 [Linux 发现](linux-discovery.md)。字面扫描器共用有界缓冲区，连续物理段保留重叠，洞不拼接。

Windows 完整/bitmap 转储提供的机器类型、PAE、DTB 和调试/链表地址仅作为候选。自动配置通过 KDBG 或完整性检查后的模块链表寻找映射 PE，再比对其身份和符号中的全局锚点；模块探测槽还必须符合类型中的 DllBase 字段。显式参数优先，发现失败保留物理分析能力并阻止内核插件成功。细节见 [Windows 发现](windows-discovery.md)。

链表遍历检查 forward/backward 一致性、尾指针、重复节点、循环和节点上限。主要字段读取失败会停止任务并保留已产生证据；可选字段使用带原因的 missing 值。当前严格模式没有自动反向恢复损坏链表，因此与上游恢复行为不完全相同。

进程 DLL 使用各进程独立 CR3 转换后读取 PEB/加载器链表，原生结构使用匹配内核符号；WoW64 的稳定基本字段使用单独四字节指针布局并记录额外布局摘要。加载器结构错误形成诊断证据，继续检查其余进程，整体任务最终失败；模块行仍可保留可读字段及不可读名称的原始错误。模块携带与 pslist 一致的进程身份，不能仅按 PID/基址合并不同 PEB 的重复记录。

## 类型与符号

ISF 用原生整数解析符号地址。读取嵌套字段时检查包含类型的边界，不把指针当作内嵌结构。数组有长度约束；位字段有位置和宽度检查。旧 DWARF 转出的 ISF 可能包含占位大类型大小，加载时不因未访问的占位类型拒绝整个文件，实际读取仍受边界限制。

`pkg/object.View` 显式绑定对象的数据层和指针目标的 native 层。内嵌成员、原址 cast 和 container 操作保留数据层；解引用从当前层读取指针后切换到 native 层，不依据地址数值猜测或在错误后回退。空指针与不可读指针分开处理。此接口为物理对象扫描提供共同底座，尚不代表 socket 扫描能力已完成，验证与使用限制见 [对象视图](object-views.md)。

符号摘要取自解压后的原始 JSON 字节；格式或内容变化会使缓存失效。Linux 验证完整 banner，包括构建标识；Windows 从已映射内核 PE 的 CodeView 记录提取 PDB GUID/Age，不接受“文件名相似”作为匹配。

ELF/Mach-O 的 DWARF 原生转换采用有界 DIE 图，支持类型前向引用、递归结构、枚举、有符号标量和匿名成员；不借助外部转换程序。输入、调试段解压、累计解析读取、DIE 数量及递归深度均有限制。多架构 Mach-O 先校验切片，再仅解析选定架构。转换后以确定性 ISF 的摘要进入证据与缓存；直接读取调试文件和读取它导出的 ISF 可共享摘要。详细限制见 [原生符号](native-symbols.md)。

本地符号索引保存内核身份和表摘要。已知 DTB 下，候选的身份必须在目标内核虚拟空间中验证；选择后加载完整表并复核内容和索引字段，随后插件执行前再次验证身份。不能读取、无匹配、多个不同表匹配和索引过期均返回错误。索引来源路径不进入任务缓存键，显式加载与索引加载同一表可复用结果；缓存仍包含精确符号摘要。

PDB/MSF 7.0 将所需流映射到文件块，解析 CodeView 前向类型、字段延续链、符号记录、PE 段和 OMAP，独立限制目录、累计读取、记录数和递归深度。PDB GUID 与 DBI Age 对应映像身份；Info Age 的差异进入转换报告。同名类型变体和地址不同的同名符号保留限定名称，绝对链接常量与 RVA 分别处理，详见 [PDB 符号](pdb-symbols.md)。

Windows 的缺失符号可在已知 DTB/内核基址下按精确 PE 身份自动获取。原始 PDB 按身份缓存，转换结果按实际引擎二进制摘要缓存，manifest 保存来源、输入/输出摘要和转换报告。命中后复核原始内容与表摘要；新的二进制可离线重用原始 PDB 并重新转换。文件锁、临时文件与独占原子发布避免并发覆盖，错误身份的下载不进入可信缓存。网络请求仅携带符号身份，不包含镜像字节。

## 任务、取消与缓存

每个插件声明参数和列。未知参数被拒绝，默认值规范化后写入 provenance。执行器支持插件依赖和循环检测；当前内置插件没有复杂依赖图。

引擎每 128 行批量写入 SQLite。输出回调失败或上下文取消后，用有时限的独立清理上下文保存待写行及终态。关闭引擎会取消并等待运行中的插件完成清理，再关闭文件和数据库。进程异常结束后，重新打开案件会把遗留 running 状态改为 failed；已完成任务可复用，失败任务重新执行并保留历史尝试。

缓存键由镜像 SHA-256、引擎版本、可执行文件 SHA-256、符号 SHA-256、层、架构、DTB、内核基址/slide、操作系统及参数共同生成。检查文件大小和修改时间变化，避免对变更的源复用缓存。输入仍需由采集/存储流程保证不可变；不宣称检测对手保留元数据的并发修改。

SQLite 使用任务/序号索引分页，结果 ID 索引用于跳转。当前筛选是对单元格 JSON 的文本扫描，深分页使用 OFFSET。全文索引、按列排序和大规模层级索引尚未实现。

## 证据与关联

每行保存类型化单元格、父证据 ID、图像摘要、符号摘要、引擎版本与构建、插件参数、层及偏移。行 ID 是规范 Go JSON 内容的 SHA-256。地址以十六进制字符串表示，uint64 为十进制字符串，字节采用 JSON base64。缺失与读取失败不合并为 null 或零。

进程身份使用镜像/层/对象地址/PID/可用启动时间；Linux 的旧 `timespec` 与现代纳秒值都可保留。Linux `PGDVirtual` 不会伪装成物理 DTB。分诊发现引用原始行 ID 并继承来源。当前关联以身份和显式证据引用为主；通用实体图、网络/文件/注册表/时间事件生产者仍待实现。

Windows 现代 VAD 索引共用严格树遍历和文件解析；`windows.vadinfo` 从目标内核 `MmProtectToValue` 读取权限映射，保留权限索引和值。直接 RWX 规则按该数值判断，逐页读取落盘结果，不依赖启动路径是否可读。Copy-on-write 映像权限不属于该规则的直接 RWX 范围。规则输入保护字段不可读时检查失败；其余未实现的输入继续报告 unavailable，整体任务不能被标为成功。

Linux 映射将 VMA 遍历、文件元数据和路径分层处理；namespace 根、全局挂载根、动态名与叶标签均显式记录作用域，原始路径字节单独保留。默认保留 inode 偏移超出大小的映射，基线过滤视图为单独参数和缓存键。Linux 的 RWX 规则消费 rwx 标志，删除/memfd 规则只对执行映射读取所需路径与删除状态，并引用原始映射；映射结构不可读和必要元数据未知均不能变成成功的空结果。

HTML、JSONL 和 ZIP 导出从持久化结果分页读取，包含任务失败和覆盖缺口。ZIP 逐成员保存摘要与行数；校验和提供完整性检查，不提供数字签名或外部时间戳认证。

提取文件由任务专属 sink 创建，只能在案件的随机任务/文件目录中独占新建。数据与缺页填充日志分别流式散列；失败、取消和未完成写入不会标为完整。schema v2 保留中断文件并将其大小/摘要标为未验证；旧 v1 案件自动迁移，旧版程序会拒绝 v2。证据包 v2 包含分页生成的 artifacts.jsonl 与可验证文件，未完成字节只保留元数据说明，不作为已验证文件打包。Windows VAD 与 Linux VMA 的 dump 生产者使用独立进程页表和逐页读取接入该接口，缺页与捕获字节明确区分。

PE 重建是单独的有界计划与流式覆盖层，原始头部、修改偏移、原值和新值作为结果保存；PE 字节不被冒充为原始磁盘布局。覆盖层只修改已成功读取的源字节，其他页面失败仍走显式填充日志。内核 ImageBase 保留完整 canonical 地址，和上游掩码差异单独验收。


`internal/library` 复用只读物理映射扫描 Linux banner / Windows 内核 RSDS，管理 `images/` 和 `sysmbols/`，并提供完整身份匹配、HTTPS 目录查询、下载校验和不覆盖发布。CLI `images inspect`、`symbols match` 和 TUI workspace 共用该服务。TUI workspace 可先管理文件，再创建原有分析模型；所有符号下载均需显式确认。身份线索与分析引擎的虚拟地址核验保持区分，见 [本地库](local-library.md)。
