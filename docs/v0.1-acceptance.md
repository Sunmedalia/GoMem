# v0.1 开发验收

v0.1 从当前 `0.1.0-dev` 开发基线开始，不创建正式 release。冻结新增插件，优先验收现有插件、修复读取/输出问题，并补齐案件验证、调查关联、分诊、导出和 TUI 工作流。

## 冻结范围

133 个原生命令（Windows 80、Linux 48、通用 5）映射到 154 个固定基线官方类。官方类包含弃用别名，不能当成 154 个独立实现。剩余 41 个官方类不纳入本阶段新增开发。原始完整对齐矩阵继续保留其状态和缺口。

[逐项清单](v0.1-plugin-inventory.json) 保存每个命令的参数、结果列、官方类映射、适用条件、语料声明、对照范围、未解决项和验证文档 SHA-256。三个 GoMem 独立通用命令无官方类映射。清单审计仅证明注册、声明与记录一致，不证明全部取证行为正确；`behavioral_acceptance=pending` 需由本次实际执行结果及后续专项验证补充。

## 本阶段验收层次

1. 工程回归：构建、静态检查、全部 Go 竞态测试、Python 工具测试、输入 fixture、矩阵和新增 fuzz。跳过的可选真实语料测试不能计入通过。
2. 冻结清单审计：133 个命令无重复参数或结果列，154 个映射都指向注册实现，验证文档存在且内容受摘要约束。审计发现 `linux.check_modules` 重复声明 `Taints` 列，已去重，并为所有注册 schema 加入回归检查。
3. 真实镜像回归：另行启用 `GOMEM_CORPUS_DIR` 执行选定字段的官方对照测试；逐个记录 pass/fail/skip。需要额外 reference 环境变量的测试若跳过，仍是待验证项。缺页导致插件任务失败，而测试正确验证了该失败语义时，可以是测试 pass，不能据此说插件在镜像上完整成功。
4. 版本/架构/参数/提取/调查验证：逐项引用原有验证文档，不把单镜像字段匹配或正常样本的空结果扩大为完整验收。

## 复现

```sh
make build
make check
make matrix
python3 tools/build_inode_mode_oracle.py --check
make audit-v01
GOMEM_CORPUS_DIR="$PWD/.cache/corpus" go test -json -count=1 -timeout 60m ./internal/engine -run '^TestOfficial' > .cache/v01/corpus-tests.jsonl
```

完整本地回归使用显式输入配置，覆盖上面会跳过的专项参考和 Kali 物理/显示设备验证：

```sh
python3 tools/run_v01_corpus.py --inputs docs/v0.1-corpus-inputs.example.json \
  --log .cache/v01/corpus-complete.jsonl --report .cache/v01/corpus-complete-report.json
```

示例配置只包含本地文件位置，不包含镜像或符号本体。运行前要求全部路径/参考 manifest 存在；缺少输入会直接报错。运行后只要有 fail 或 skip 就返回非零，原始日志与汇总报告分别保留，已有输出不会被覆盖。参考来源及内容摘要仍由各 corpus 测试核对。

本地 Python 使用 3.12 或更新版本。正式基线验收继续使用 `docs/capabilities.json`；当前 0 accepted 不影响 v0.1 的增量工程验证，但也不会因本阶段检查通过而自动改变。

更新支持范围或验证记录后，显式审阅再运行：

```sh
go run ./cmd/gomem plugins --format json > .cache/v01/native-plugins.json
python3 tools/audit_v01.py --plugins .cache/v01/native-plugins.json --write
make audit-v01
```

## 2026-10-23 执行结果

工程回归 `make check` 已通过：Go vet、全部非引擎包竞态测试、384 个引擎测试/seed 函数的四个竞态分片、44 个 Python 测试及 428 个参数 fixture。随后新增审计、日志汇总器和显式语料运行器后，Python 测试增加到 52 个并通过；133 个 schema 和受影响的 CheckModules 引擎竞态测试通过。矩阵、32,768 个 inode mode、34 个 Shimcache 版本选择 oracle 及三个新增 fuzz 共 30,000 次通过；本地构建和离线 doctor 通过。

真实镜像首轮在 `eb33861` 代码上执行，为 101 pass / 0 fail / 16 skip。随后找到本地专项参考输入，使用 `9d7829a` 原生源码和显式语料运行器补跑：[最新完整顶层测试执行清单](v0.1-corpus-execution.json) 为 **118 pass / 0 fail / 0 skip**，无子测试跳过，包含此前 16 个专项测试、Kali 物理 VMCOREINFO 和额外的 ARM64 显示设备采集/导出/缓存冒烟测试。这里的 118 是测试函数数，不能换算为 118 个插件完整验收通过。报告保留执行命令、输入配置摘要及原始 JSONL 日志摘要。
